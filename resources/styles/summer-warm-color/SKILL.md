采用晴朗夏日绘本风，整体以明亮的天空蓝、阳光晒过的草地绿和温暖的阳光黄为骨架，点缀粉嫩暖色，营造清新、治愈、童真又充满夏日活力的视觉氛围——像夏日午后躺在草地上看云飘过的那种没心没脑的快乐。

## 配色

整体调色来自一张真实的"夏日碎片"色卡：天空、阳光、草地三色撑起画面骨架，再用暖橙和粉色做呼吸点，避免单一色调的沉闷。

- 主色（天空）：晴空蓝 `#20A1EE`，带一点点更深的蓝 `#58C3F6` 做层次和阴影，让天空不死板。天空在画面中占大头，是基调。
- 主色（草地）：草绿 `#9DDF67`，嫩绿高光 `#DAF5A7` 过渡，像被阳光晒过的草尖。
- 强调色（阳光）：明黄 `#FFF061`，用于太阳本体、关键标题、点睛色块——是整张图的"温度来源"，让蓝绿调不至于冷。
- 暖系点缀：暖橙 `#FE7F08`、淡粉 `#FFADDD`、浅蓝紫 `#A6B0FF`——做童趣感的呼吸，小面积使用，不要大面积铺。
- 文字色：纯白 `#FFFFFF` 叠在天空蓝上，深灰 `#3A3A3A` 用在浅色草地上的小字。

情绪关键词：明亮、清新、治愈、温暖、童真。饱和度整体中等偏暖，不要刺眼的高饱和，也不要灰扑扑的低饱和。**蓝是主调，黄是温度，绿是生机**——三者缺一不可。

## 排版

标题是这套风格的灵魂——要像软笔手写体，笔画流畅、带连笔和一点点随意的艺术感，传达"夏日回忆"的松弛。中文标题用偏粗的毛笔/软笔风手写体（字重 600–700，白色叠在蓝天上形成柔和对比），英文小标（如 "summer"）用斜体手写体，轻盈一些。

正文与说明用简洁的无衬线体（思源黑体 / 苹方这类），字重 400，字号比标题小一档，留出呼吸——它们的作用是托住标题而不是抢戏。中英文都不要太锋利的几何无衬线，圆润一点更贴合治愈感。

## 插画与装饰

插画是水彩+彩铅质感的卡通手绘，意象要具体、可复刻，不要泛泛的"装饰元素"：

- 自然意象：带放射光芒的卡通太阳（黄色圆+光线）、蓬松像棉花糖的云朵、渐变草地、几朵小花。
- 童趣物件：纸飞机（白色，两三架，斜飞做动感）、彩色气球、小风车。
- 人物：穿简单T恤的小孩，**躺卧或仰躺在草地上**的姿态（看天、放松、发呆）——这是"夏日碎片"的标志性意象，传达悠闲而非奔跑。
- 装饰容器：竖排色块（带水彩笔触的"刷痕"质感）、底部圆形色卡（5 个一组做渐变）、手写签名式小字（如蓝色 "Summer" 签名落在草地上）。

色块和色卡不是冷冰冰的方块——要有水彩晕染的笔触感，边缘柔和，传递"手作温度"。

## 布局

典型布局是"上场景 / 中标题 / 下色卡"的三段式：

- 顶部：大幅天空场景（蓝天+太阳+云朵+仰躺人物）奠定情绪，占画面 50%+。
- 中部：醒目的手写体主标题，左右各留至少 12% 边距让标题呼吸。
- 底部：草地过渡 + 圆形色卡阵列展示配色体系。
- 模块化卡片也适用，用圆角矩形（圆角 16–24px）+ 柔和投影组织信息块。

留白是为了让标题的呼吸感托住情绪——不要把画面填满，留出天空的"空白地带"。

## 组件与装饰

**标题处理**：标题手写白字叠在天空蓝大色块上（云朵衬托），或阳光黄底深蓝字；英文小标用斜体手写体。
**卡片**：白云形 / 大圆角容器 + 天蓝描边，或冰棒形竖条卡片；卡片允许错落排布如夏日贴纸墙。
**表格与图表**：表头天蓝底白字；图表用天蓝 / 草地绿 / 阳光黄，粗描边 + 明快填色。
**装饰母题**：太阳、云朵、游泳圈、冰棒、西瓜籽点；夏天的元素明亮饱和，但每页控制在 2-3 种。

## 动画

节奏舒缓，缓动用 `ease-out`，时长 `0.8s–1.2s`。太阳可轻微脉冲发光，云朵和纸飞机可水平浮动 ±8px，草地色卡错位淡入。文字从下方轻滑入 12px 并淡入。整体不要快切和弹跳，要像夏天的风一样慢慢来。

## 适合场景

面向儿童、青少年、家庭亲子、心理成长、教育科普、夏日休闲活动、户外野餐露营、治愈系品牌宣传、绘本海报、社交媒体"夏日日常/夏日碎片"分享的温暖型 PPT。

## 不要

- 不要高饱和刺眼的霓虹色或荧光色——会破坏治愈感。
- 不要尖锐几何、硬朗锋利的线条、直角矩形——这套风格是圆润和柔和的。
- 不要复杂渐变mesh或强烈硬阴影——用柔和的水彩晕染代替。
- 不要冷色调主导（大面积冷蓝灰无暖色）——必须有阳光黄的温度打底。
- 不要密集排版——保持天空草地的呼吸感，信息块之间留足间距。
- 不要奔跑/剧烈动感的姿态——这套是"躺下来看天"的悠闲，不是运动风。

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 夏日暖色的推荐构图

- 以天空、草地和人物构成完整场景，信息沿场景路径安排；插画元素不拆成独立卡片装饰。
- 优先风景/人物主视觉 + 短文案、横向故事、三段体验或柔和分栏；给画面保留呼吸，但内容页不能只在顶部摆几张小卡。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片采用统一暖色温、清晰主体和自然负空间；图表用低饱和暖色序列与直接标注，确保对比度而不是只追求柔和。
- 圆角、柔色块和小图标可以少量出现，但不叠套卡片、不堆胶囊；温暖来自色彩、图像与节奏，不来自组件数量。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“夏日暖色”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
