采用勃艮第红 + 玫瑰金 + 黑的高级配色，整体气质沉稳、奢华、精致，带有红酒般的醇厚与贵气——是那种一眼就能看出"贵"的设计感，而不是堆砌金光。

## 配色

调色来自一张真实的"勃艮第红高级感配色"色卡：深酒红打底定调，黑做底色把饱和度顶起来，玫瑰金和暖黄做点睛，深灰做平衡。

- 主色（基调）：勃艮第红 `#81021F`，深红偏紫，像陈年红酒，饱和度高但明度克制——这是整套配色的灵魂，占主导面积。
- 背景色：纯黑 `#000000`，做底色衬托主色，让红的饱和度和金的光泽都被"放大"。
- 强调色：玫瑰金 `#F8B37F`，浅橙红偏金属暖调，用于主标题、品牌名、关键符号——带来温度和精致感，中和红的厚重。
- 辅助强调：拿坡里黄 `#FDD95F`、明黄 `#FFD700`——用于次级标题、色号、点缀，与玫瑰金形成暖色层次。
- 平衡色：深灰 `#363636`，近黑但略浅，做色块和分隔，避免大面积纯黑的压迫。
- 互补点缀：晴山蓝 `#093D77`（深蓝偏紫），小面积使用，与暖色形成互补，丰富层次。

情绪关键词：高级、奢华、精致、成熟、沉稳、有质感。整体明度偏低、对比强烈、暖色为主。

## 排版

字体走现代几何风，要"重"——这是高级感的来源。

- 主标题（如 "COLOR"）：粗体几何无衬线，笔画粗壮、棱角分明（Arial Black / Impact 这类气质），字母间距宽松（letter-spacing 0.08–0.15em），强调力量感和视觉冲击。
- 中文标题（如 "勃艮第红 · 高级感配色"）：粗体无衬线（思源黑体 Heavy / 苹方 Heavy），字重 700–900，与英文标题气质统一。
- 正文与说明：中等粗细无衬线，字重 400–500，简洁易读，不抢戏。
- 色号标注（#81021F 这类）：小字号无衬线，置于圆角矩形色块内，专业感。

字色处理：红色背景上用暖黄/玫瑰金文字，黑色背景上用白或玫瑰金——靠对比拉开层次，不要红底配红字、黑底配深字。

## 插画与装饰

装饰母题克制但精致，不堆砌：

- 心形符号（♥）：小面积玫瑰金/暖黄心形，三五成组排在"灵感"类文字旁，传递"喜爱/推荐"的情感，打破纯文字的严肃。
- 圆角矩形色块：带轻微"对话气泡"弧度或小尾巴的标签形色块（圆角 12–16px），用于展示配色方案，比纯方块更有设计感。
- 品牌标识：简洁的几何 Logo（字母形或方形 Z 标），左上角小尺寸，强化专业识别。
- 金线/分隔线：极细的玫瑰金水平线（1px）做章节分隔，传递精致。
- 不要花哨插画、不要照片、不要复杂图形——留白和色块本身就是装饰。

## 布局

布局走"杂志封面式"的强对比结构：

- 主标题占据视觉中心，字号要大、字重要重，是绝对的焦点。
- 上下或左右分区：上部深色块（勃艮第红/黑）放标题，下部留白或浅色块放色卡和说明。
- 色块阵列：2–4 个圆角标签色块横向排列，每个带色号标注，模拟"配色方案展示卡"。
- 信息层级严格：主标题 > 副标题 > 色块标签 > 色号小字，四级清晰。
- 留白克制但不局促——黑和深红本身就是"视觉重量"，不需要塞满。

## 组件与装饰

**标题处理**：标题置于勃艮第红底反白（米白字）的横幅中，或白底深红衬线字 + 上下玫瑰金 #C9A876 双细线；封面标题可配金线框。
**卡片**：米白底，1px 酒红边框，四角玫瑰金小角饰（L 形 8px 细线），阴影极浅或不用；卡片头部可用酒红细条。
**表格与图表**：表头酒红底米白字，数据行用米色隔行；图表主色酒红，辅玫瑰金与深灰，网格线弱化为米灰。
**装饰母题**：玫瑰金细线分隔、丝绒质感的暗红大面积留白、金色大数字、简约缠枝纹角饰；贵气体现在材质感而非装饰密度。

## 动画

节奏稳重，不要轻浮。缓动用 `cubic-bezier(0.22, 0.61, 0.36, 1)`（强 ease-out），时长 `0.6s–1.0s`。

- 标题字逐字或分词淡入 + 轻微上移 8px，间隔 80–120ms。
- 色块从右侧滑入并淡入，错位 100ms。
- 金线从左向右展开（scaleX 0→1）。
- 心形可做一次性轻微脉冲（scale 1→1.08→1）。
- 不要弹跳、不要旋转、不要快速闪烁——这套风格要"沉得住"。

## 适合场景

品牌 VI 设计、奢侈品/高端化妆品包装、艺术展览海报、品牌发布会、高端餐饮/酒店宣传、时尚杂志封面、设计工作室作品集、年终总结/高端汇报、需要"贵气"的商务场合。

## 不要

- 不要用浅色、粉嫩、马卡龙色——会稀释高级感。
- 不要手写体、不要圆润可爱字体——这套是锋利和精致的。
- 不要高饱和荧光色——红要醇厚不要刺眼。
- 不要花哨插画、卡通元素、emoji——装饰必须克制。
- 不要大面积留白配小字——会显得空和廉价，要有视觉重量。
- 不要超过 4 种主色同时铺——色彩层级要清晰，勃艮第红永远是主角。

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 勃艮第红高级感的推荐构图

- 优先产品、品牌、人物或一句主张的大画面，玫瑰金只点亮标题、数字或细分隔线。
- 优先杂志封面式标题、产品/材质大图、数字或引语主导、强比例左右分栏；每页保留一个高级视觉焦点，信息宁少勿碎。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片采用高品质静物、人物、建筑或材质特写，裁切大胆但主体完整；图表只在必要时使用，并以细线、低饱和底色和单一金属强调色呈现。
- 用色块、细金线和材质对比建立层次，不堆金边、徽章、发光或浮动卡片；奢华来自比例、克制与图像品质。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“勃艮第红高级感”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
