采用樱花季慢生活绘本风，整体以莫兰迪低饱和的樱花粉、湖水蓝、草地绿为主，营造宁静、治愈、温柔、浪漫的视觉氛围——像春末初夏午后，坐在樱花树下看湖的那种"时间慢下来"的感觉。它跟明亮夏日的区别在于：饱和度整体偏低，没有刺眼的橙黄，所有颜色像蒙了一层薄雾。

## 配色

调色来自一张真实的"夏日另一种可能"色卡：粉、绿、蓝三色莫兰迪化处理，彼此不打架，整体偏粉调暖底。

- 背景色：浅米粉 `#F7E7DD`，天空和整体画面的基底，柔和低饱和，是"蒙雾感"的来源。
- 主色（樱花）：淡粉 `#FBC0CB`（花瓣浅层）+ 玫粉 `#CC6F88`（花瓣深层、草地小花），粉得有层次不平面。
- 主色（草地）：草绿 `#72AB60`，饱和度适中，比夏日活力的草绿更安静一档。
- 主色（湖水）：湖水蓝 `#5BA0AD`，浅蓝低饱和，与绿色形成清新对比但不冷。
- 文字色：深棕 `#3A2A22`（小字）或纯白叠在深色上；标题用浅粉 `#FBC0CB` 或玫粉 `#CC6F88`。

情绪关键词：宁静、治愈、温柔、浪漫、慢生活。**饱和度刻意压低**——这是它和"夏日暖色"最根本的区别，不要把颜色调亮。

## 排版

字体要"轻"，传达慢节奏：

- 主标题（如 "向阳"）：圆润手写体或软笔书法，笔画流畅、带轻微倾斜，字重 500–600，颜色用浅粉或玫粉呼应画面，不抢焦点。
- 诗句小字（如 "风暖并消融，万物始发生"）：细宋体或细等线体，字重 300–400，字号小，颜色接近背景的米白/浅棕，安静地待在角落。
- 主题落款（如 "色彩沉溺 | 夏的另一种可能"）：圆润黑体或手写体，中等字号，深棕或黑，做收尾签名。
- 英文配字：细斜体手写，轻盈。

中英文都避免粗重几何无衬线——那种"重"会破坏慢生活的呼吸感。

## 插画与装饰

插画是水彩+彩铅质感的柔和手绘，所有元素都"静"，不要动感强烈的：

- 自然意象：盛开的樱花树（花瓣密集下垂）、平静的湖水、湖岸芦苇（顶端带橙色小花）、草地上的淡粉小花、远处起伏的草地曲线。
- 动物：优雅的天鹅（白羽橙喙）、温顺的小狗（浅黄）、画面上方两只飞鸟剪影。
- 人物：戴黄色草帽、穿柔和色衣服的女孩，坐在树下小椅上，背对或侧坐，姿态放松——不要正脸大特写。
- 装饰容器：右侧竖排水彩笔触色条（带刷痕质感）、底部圆形色卡阵列、手写签名式小字。

所有插画边缘要柔和晕染，不要硬边和锐利轮廓。

## 布局

典型是"远景 / 中景 / 近景"的三层风景构图：

- 远景（上）：樱花树冠铺满顶部，花瓣层次丰富，奠定浪漫基调。
- 中景（中）：湖水+草地+人物动物，构成静谧的场景中心。
- 近景（下）：色条/色卡阵列展示配色体系，或一行诗句落款。
- 文字克制：手写标题放角落（左上或左下），诗句竖排小字点缀，不要大面积文字块。
- 留白要足——天空和湖面的"空"是治愈感的一部分，不要填满。

## 动画

节奏极慢，缓动用 `ease-out`，时长 `1.2s–1.8s`（比夏日活力风更长）。

- 樱花花瓣可轻微飘落（translateY + rotate，幅度小、速度慢）。
- 湖水可做极轻微的水平波纹（scaleX 1→1.02）。
- 文字淡入，不要位移或仅 4–6px 轻滑。
- 天鹅、小狗保持静止或极轻微呼吸（scale 1→1.02）。
- 绝对不要快切、弹跳、旋转——这套风格要"慢到让人想深呼吸"。

## 适合场景

春日/初夏主题、慢生活/治愈系内容、赏樱/踏青活动、文创产品（明信片/插画/手账）、家居软装、女性/生活方式品牌、婚礼/浪漫场合、诗歌散文配图、社交媒体"春日日常"分享。

## 不要

- 不要高饱和明亮色——会破坏莫兰迪的蒙雾感。
- 不要纯黑大块或强烈明暗对比——要柔和过渡。
- 不要动感强烈的元素（奔跑、跳跃、爆炸）——这套是"静"。
- 不要粗重几何字体、不要锋利线条。
- 不要把粉色调成廉价马卡龙粉——要有灰度，是"莫兰迪粉"不是"少女粉"。
- 不要拥挤——天空和湖面的留白是灵魂。

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 樱花治愈的推荐构图

- 樱花树、湖面或人物场景作为主视觉，文字保持短而温柔；花瓣仅做阅读方向的少量点缀。
- 优先图片主导的左右分栏、中心主视觉 + 两侧短信息、三段叙事或柔和的对比构图；内容页保持低到中密度，避免整页均匀铺满小卡片。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片应明亮、自然、具有生活感，统一色温与裁切；图表降低饱和度，以直接标注代替复杂图例，重点数据使用一处暖色或主题色。
- 可少量使用柔和色块、细描边或主题化小图标作为锚点，但同组模块必须一致；圆角和阴影都要克制，不能出现应用界面式组件堆叠。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“樱花治愈”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
