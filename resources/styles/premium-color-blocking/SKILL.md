高级撞色风格追求一种**时尚编辑大片**般的戏剧张力——用大胆却克制的撞色，把日常信息排版成有态度的画面。它不是花花绿绿的喧闹，而是像《Vogue》《Wallpaper》封面那样，靠两到三种高纯度色块的强力对峙，托出一种克制的高级感。整体节奏要稳、留白要狠、字体要利落，让色彩本身成为情绪的主角。

## 配色
核心是"暖橙 × 冷墨"的强对峙：主暖色用珊瑚橙 `#FF6B47` 与琥珀橘 `#F5A623`，传递温度与自信；对峙冷色用深墨蓝 `#1B2A4A` 与午夜青 `#0F3B4C`，压住暖色的躁，让画面沉下来；中性背景用奶白 `#F4EFE6` 与象牙 `#EDE4D3`，给撞色留呼吸空间；强调点缀用一点正红 `#E63946` 或柠黄 `#F4D35E`，只在标题、数字、关键标点上点一下，像项链上的那颗主石。色彩比例大致是 暖 45% / 冷 30% / 中性 25%，比例失衡会立刻垮掉高级感。

## 排版
标题用粗壮的几何无衬线（思源黑 Heavy / Inter Black 之类），字重 800–900，字距收紧到 -2%，传递"我说了算"的确定感；副标题同字族降到 500，留出呼吸；正文用清爽无衬线 400 字重，行高 1.6。中文配思源黑体，英文配 Inter 或 Helvetica Neue。数字和引语可以放大成展示字，让排版有节奏起伏。

## 插画与装饰
装饰母题走"色块切割"路线：大面积平涂色块、斜向切分构图、几何形状（圆/半圆/粗线条）做视觉锚点；可以点缀极简线描（一只手、一片叶、一个抽象侧脸）增加人文气息；不要写实景插画、不要拟物阴影。色块边缘要锐利干净，像丝网印刷的质感。

## 布局
借鉴杂志版式：网格严谨但敢于破格。常见结构是左大色块右白底文字、上下撞色对半切、或中心图片被色块环绕。关键标题可以越出版心、与色块咬合。模块之间用粗实线或色带分隔，而不是细弱发丝线。整页元素不超过 5 个层级，多了就乱。

## 动画
节奏要干脆利落，像翻杂志的"啪"一下。色块用 ease-out 0.5–0.7s 滑入或淡入；文字稍滞后 0.2s 上滑 16px；强调数字可以带一点放大弹跳（scale 0.9→1，cubic-bezier(0.34, 1.56, 0.64, 1)）。避免柔长缓动——那会拖垮撞色的力量感。

## 适合场景
品牌发布、时尚潮流、年度总结、产品发布会、创意提案、视觉作品集

## 不要
- 不要超过三种主色，撞色不是彩虹
- 不要柔粉、马卡龙、莫兰迪这类低饱和温柔色——它们和"高级撞色"气质相反
- 不要渐变背景或毛玻璃模糊，平涂色块才是主角
- 不要拟物阴影、不要 3D 立体效果，保持平面丝网印刷感
- 不要花体字或衬线字体做正文，会破坏现代利落感
- 不要元素挤满画面，留白是撞色高级感的另一半

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 高级撞色的推荐构图

- 每页只使用两到三个主色块建立强比例关系，文字跨栏要克制，避免把色块切成小卡片。
- 优先非对称编辑网格、主图 + 标题、引语 + 证据、跨栏数字、封面或专题页；像编辑一张跨页而不是排一个网页信息流。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片承担叙事，使用大幅裁切、人物视线与文字负空间；图表采用编辑化直接标注和少量注释，不使用仪表盘式小图集合。
- 用栏线、页码、题注、色块或 pull quote 建立节奏，避免文章卡片列表、导航标签和新闻网站式组件。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“高级撞色”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
