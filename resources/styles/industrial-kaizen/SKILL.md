表格即视觉。这是一种以**表格为主要视觉语言**的现代商务风格——没有插画、没有色块、没有装饰图形，信息通过严密的行列网格、克制的分割线和精准的数字对齐来传递。它呈现的是编辑级报表的专业气质：可以承载较高信息密度，但密度必须由内容必要性决定，并通过留白和细线呼吸。

## 配色
暖白底 #FBFAF6 作为画布，承载所有内容；表格行间分隔用 #EDE9DC（暖灰），区块强分隔用 #1F1E1A（深墨）1px——只出现在标题下沿、表头底部和合计行。文字色阶三档：标题/重点数字 #1F1E1A、正文 #2A2924、辅助/标签 #8B8478。状态徽章用文字+边框/底色表达——`运营中` 用 #1F1E1A 实底反白、`观察` 用 #EDE9DC 浅底深字、`达成` 用透明底+1px 边框。整体低饱和、高明度的暖中性色系，**禁止任何彩色**。

## 排版
标题用粗壮无衬线（PingFang SC Semibold / 思源黑体 Semibold），字号大、字距收紧 -0.015em，行高 1.15 传达紧凑感。正文用 Regular 字重，强调功能性。**所有数字必须用 tabular-nums 等宽数字字体**——KPI、金额、百分比、计数全部右对齐到个位/小数点，多列数字必须能视觉连成一条竖线。表头标签全大写、字距 0.08em、灰色 #8B8478，与正文形成层级。中文不用衬线、不用手写体；英文配 Inter / Helvetica Neue / Arial 等几何无衬线。

## 装饰母题
**几乎没有装饰**。允许的视觉元素只有四种：
- **细分割线**（#EDE9DC，1px）——构成所有表格行间的呼吸骨架
- **强分割线**（#1F1E1A，1px）——只用在标题下沿、表头底部、合计行上下，像账本的封边
- **状态徽章**——`运营中 / 观察 / 达成 / 收缩中`，用底色或边框表达，2px 圆角
- **▲▼ 趋势符号**——只在 KPI delta 处使用一次，不开装饰图形

不要渐变、不要阴影、不要圆角超过 2px、不要任何位图、不要图标。

## 布局
以**表格 + KPI 横栏**为典型结构。只有当页面内容确实是经营数据、明细、矩阵或进度表时才使用高密度表格；普通内容页仍保持低到中密度。典型结构：
- 顶部标题区（小字 eyebrow + 大字 H1 + 右对齐元信息），下方一条 1px 暖灰分隔线
- KPI 横栏（4 列等宽，列间细竖线分隔），上下用 1px 暖灰线封边
- 主表格区（表头粗线、行间细线、合计行底色稍深 #F2EFE5），列宽用 colgroup 严格控制
- 页脚（左侧状态信息点列、右侧报告标识），1px 暖灰线封顶

所有元素严格对齐到网格——左边距、栏间距、行高、数字右对齐位置全部统一。**对齐是这套风格的信仰**，错位一像素都比配色错误严重。

信息密度可以较高，但必须可读，并通过留白和细线呼吸；不要为了"报表感"多塞行列。信息过多时优先合并、分组、突出关键行，而不是把页面填满。

## 动画
几乎不用。必要时只用两种：
- 表格行从下淡入（translateY 4px → 0 + opacity 0→1，0.3s，ease-out）——逐行错峰 40ms，传达"逐条审视"的节奏
- KPI 数字 count-up（0.4s，ease-out）——只在首次出现时一次

不做柔和缓动、不做循环、不做炫技入场。动画的目的是**让信息按讲述节奏出现**。

## 适合场景
经营周报、季度复盘、年度总结、KPI 看板、销售明细、财务报表、产品矩阵对比、项目进度汇总、运营数据复盘、市场调研结果——任何需要"让数据表格自己说话"的商务汇报场合。

## 不要
- 不要任何彩色（红黄绿蓝紫橙一概不要，状态用底色深浅或文字标签表达）
- 不要圆角过大（最多 2px）、不要阴影、不要渐变
- 不要插画、照片、位图、emoji、图标
- 不要装饰性字体、手写体、衬线体
- 不要花哨入场动画或循环动画
- 不要为了报表感牺牲可读性——这套风格的"好看"等于"信息清晰"
- 不要让数字列不对齐——tabular-nums 和右对齐是硬要求
- 不要斑马纹（zebra striping）——靠行间细线就够，斑马纹会污染数据可读性

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 表格 · 现代周报的推荐构图

- 以问题—原因—改善—结果的链路组织页面，工业黄只标风险、节点或改进结果。
- 优先执行摘要、主图表 + 结论、左右对比、关键数字 + 证据链、清晰流程；一页只保留一个主结论，主体区必须明显大于辅助信息。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片使用真实业务场景、产品实拍或信息图，裁切干净；图表使用同一主色的明度层级，仅给关键系列使用强调色，坐标、单位、图例必须清楚。
- 模块依靠网格、细分隔线和留白建立秩序；默认不加图标底座与装饰填充，避免把商务汇报做成后台仪表盘。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“表格 · 现代周报”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
