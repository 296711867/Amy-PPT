采用儿童节童趣绘本风，整体以暖橙渐变打底，搭配明亮的草绿和粉嫩点缀色，营造活泼、可爱、充满节日欢乐的视觉氛围——像幼儿园六一联欢会海报那种热热闹闹、甜甜暖暖的感觉。它跟"夏日晴朗蓝绿"的区别在于：橙是主调，蓝退到点缀位，整体更"暖"更"甜"，是儿童节的专属气质。

## 配色

调色来自一张真实的"童趣世界 CHILDREN'S DAY"色卡：橙色天空铺满画面，草地和人物在暖色里跳出来。

- 主色（背景/天空）：暖橙渐变，顶部亮橙 `#FF7F00` → 底部暖橙 `#FFA500`，模拟夏日夕阳或节日的温暖底色——橙色占画面主导，是这套风格的灵魂。
- 主色（草地）：明亮草绿 `#70D422`，饱和度高，与橙色形成强对比，传递"生机、童真"。
- 强调色：亮橙 `#FE7F08`（木马、装饰物）、暖黄 `#FEBB3E`（天空过渡、点缀）。
- 童趣点缀：淡粉 `#FFADDD`（女孩上衣、气球）、浅蓝紫 `#A6B0FF`（女孩裤子、冷色平衡）、纯白 `#FFFFFF`（纸飞机、云朵）。
- 文字色：草绿 `#70D422`、亮橙 `#FE7F08` 做标题（叠在橙底上跳出来），深棕 `#5A3A1A` 做小字。

情绪关键词：活泼、可爱、童趣、温暖、节日欢乐。饱和度整体偏高（比夏日蓝绿款更鲜艳），但靠橙暖调统一，不刺眼。

## 排版

标题要"童真"——圆润、笨拙、带涂鸦感的稚拙美。

- 中文主标题（如 "童趣世界"）：圆润粗手写体或卡通字体，笔画圆润、结构松散，像小孩涂鸦的"稚拙感"，字重 700–800。颜色用草绿或亮橙，叠在橙底上形成强对比，跳出来。
- 英文小标（如 "CHILDREN'S DAY"）：简洁无衬线体，放在主标题下方做标签，可用色块底+白字或紫粉字。
- 正文与说明：圆润无衬线体（圆体/幼圆这类），字重 400–500，亲和力强，不要锋利几何。

## 插画与装饰

插画是高饱和卡通手绘，物件要"具体可识别的玩具感"：

- 核心意象：**木马**（棕色卡通造型，小孩骑在上面）——这是儿童节的标志性物件。
- 童趣物件：纸飞机（白色，成对出现做动感）、彩色气球（粉/蓝/黄/橙/绿一组）、彩色皮球、小风车、彩旗串。
- 人物：穿鲜艳色衣服的小孩（粉上衣+蓝裤子这类高对比搭配），动作活泼（骑木马、举球、跳跃）。
- 自然点缀：蓬松云朵、几朵卡通小花。
- 装饰容器：右侧竖排色块（粉/蓝/黄/橙/绿，带刷痕质感）、底部圆形色卡阵列（5 个一组）——展示配色体系。

所有插画轮廓要圆润饱满，不要细线条和锐角——儿童节的视觉是"圆、胖、软"。

## 布局

典型布局是"中央主体 + 周边点缀"：

- 中央：主体插画（小孩骑木马/举球）做视觉焦点，占画面中部。
- 上方/标题区：醒目的卡通手写大标题 + 英文小标签。
- 下方/边缘：色块和色卡阵列展示配色，或彩旗/气球做装饰边框。
- 也可用模块化卡片，圆角矩形（圆角 20–28px，比夏日款更大更圆）+ 柔和投影。

布局可以"热闹"一点，但热闹来自主视觉、装饰和色彩节奏，不是把内容塞满。正文信息仍保持低到中密度，卡片或色块按内容需要少量出现，保留天空、草地和角色周围的呼吸空间。

## 组件与装饰

**标题处理**：标题字体圆润带涂鸦感，可坐在一朵手绘云或橙色蜡笔框上；标题旁点缀太阳 / 星星手绘贴纸。
**卡片**：大圆角（16px 以上），白底 + 2px 橙色虚线边框，像贴纸一样允许 1-2° 微旋转，不用真实阴影而用色块投影。
**表格与图表**：表格改成彩色行条——草绿、粉橙交替底色 + 圆形序号徽章；图表用明快绿粉橙填色、粗描边，形状圆润。
**装饰母题**：手绘星星、气球、蜡笔涂鸦线、纸胶带贴角、圆点花纹边；一切装饰都保持"小朋友画的"稚拙感，不追求对称精确。

## 动画

节奏活泼轻快（比夏日蓝绿款快一档），缓动用 `cubic-bezier(0.34, 1.56, 0.64, 1)`（带轻微回弹），时长 `0.5s–0.9s`。气球和纸飞机可上下浮动 ±10px，木马可轻微摇摆，色卡可弹跳式淡入。文字可带一点弹性入场。整体要有"节日感"的雀跃，但不要眩晕式快闪。

## 适合场景

儿童节、幼儿园/小学活动海报、亲子活动邀请函、童装/玩具/绘本宣传、生日派对、少儿教育课程、家庭亲子品牌、需要"甜甜暖暖可爱"气质的节日营销。

## 不要

- 不要冷色调主导（大面积蓝绿）——这套是橙暖的主场，蓝只做点缀。
- 不要锋利几何、细线条、直角——儿童节要圆胖软。
- 不要低饱和灰调或莫兰迪——会显得"老气"，儿童节要鲜艳明亮。
- 不要成人化的精致排版——保留一点"稚拙感"才对味。
- 不要复杂的写实插画——卡通简笔/平涂色块更合适。
- 不要深沉的暗色背景——必须是明亮的橙暖底。

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 童趣橙暖的推荐构图

- 用一幅核心儿童插画带动阅读，信息控制在三组以内；玩具、气球等只做边缘叙事线索。
- 优先风景/人物主视觉 + 短文案、横向故事、三段体验或柔和分栏；给画面保留呼吸，但内容页不能只在顶部摆几张小卡。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 图片采用统一暖色温、清晰主体和自然负空间；图表用低饱和暖色序列与直接标注，确保对比度而不是只追求柔和。
- 圆角、柔色块和小图标可以少量出现，但不叠套卡片、不堆胶囊；温暖来自色彩、图像与节奏，不来自组件数量。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。
