整体采用沉稳的新中式高级感视觉：像故宫宫墙在傍晚光线里的深红，搭配玄石般的深灰与宣纸米色，气质克制、厚重、安静，但标题要有强烈存在感。画面不要做得花哨，而是用大色块、粗字体、圆角分区和极少量装饰，把"东方审美里的力量感"表达出来。

## 配色
主色使用故宫墨红 #8C3232，带一点砖红和酒红的沉淀感，适合作为封面背景、大标题区、重点卡片或强调色。深色辅助色使用玄石灰 #363636，像磨砂石材一样沉稳，可用于次级模块、页脚或深色信息区。背景色使用宣纸米灰 #CAD2C5，温润、低饱和，适合承载正文与留白区域。文字建议使用米白灰 #DAD8CC 或浅宣纸色 #E6E1D3，避免纯白过刺；在浅底上正文可使用深炭灰 #2F2F2F，重点词可回到墨红 #8C3232。

## 字体
字体选择厚重、现代、无衬线的黑体风格，标题要粗、方、稳，字重接近 Heavy 或 Bold，字距略收紧，形成有压迫感的视觉重心。正文使用中等字重的无衬线字体，保持清晰、利落，不要使用过于圆润可爱的字体。中文标题可以采用大字号分行排布，像碑刻或匾额一样有分量；英文或品牌字样可使用粗圆几何感字体，但颜色和气质必须收住，不能变成潮牌霓虹感。

## 布局
版式以大面积色块分层为核心，强调横向卡片、上下分区和强对齐。页面可以用 2-3 个宽大的圆角矩形区域堆叠，形成类似色卡或展板的结构；每个模块内部信息不宜过多，保留厚实的边距，让画面显得贵气而不拥挤。标题通常放在左上或视觉高位，字号巨大，副标题或标签放在右上角，用胶囊形描边框承载。信息标注可放在右下角，形成稳定的对角线平衡。

## 组件
组件以大圆角卡片为主，圆角半径偏大，约 24-40px，边缘柔和但整体仍然有厚重感。可使用深黑色外框或投影制造"压住画面"的边界感，阴影要大而实，像厚纸板或装裱框的层次，不做轻飘飘的玻璃拟态。标签组件适合使用细描边胶囊框，描边颜色可用浅米灰 #CFC8BA，文字同色，营造低调印章感。装饰元素尽量克制，可以少量使用短横线、色值标注、印章式小标签，不要加入复杂花纹。

## 图形与质感
整体图形语言偏平面色块，不依赖插画。若需要加入图形，可选用宫墙、石阶、宣纸纹理、印章、匾额、窗棂的抽象轮廓，但必须极简化处理。背景可以加入非常轻微的纸张颗粒或磨砂噪点，透明度控制在 3%-6%，让色块有真实材质感。不要使用高亮渐变、金属反光或强烈发光效果，质感应是沉静的、哑光的、可触摸的。

## 动画
动画节奏要稳，不要弹跳。推荐 Anime.js v4 使用 0.6s-0.9s 的入场时长，缓动可用 easeOutCubic 或 easeOutQuart。大色块从下向上轻微滑入或以 opacity 淡入，移动距离控制在 20-40px；标题可以逐行淡入并轻微上移，形成庄重开场。标签、标注信息延迟 100-200ms 出现即可，整体像展板缓缓落位，而不是快速闪现。

## 适合场景
适合需要表达文化底蕴、审美判断、品牌质感或高端内容的 PPT，比如传统文化主题、品牌提案、色彩审美分享、艺术设计课程。

## 不要
- 不要使用高饱和亮红或荧光色，避免廉价喜庆感
- 不要使用复杂渐变、强发光和玻璃拟态
- 不要堆叠过多装饰纹样，保持克制
- 不要让文字过小过密，留出厚重呼吸感
- 不要使用可爱圆体或花哨手写字体

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 故宫墨红的推荐构图

- 宫墙红建立视觉骨架，玄石灰承载内容，宣纸米负责留白；纹样和印章只点到为止。
- 优先横向长卷式阅读、主景 + 题签、留白中的观点、诗意左右分栏或三段递进；竖排只用于 2–6 个汉字的短题签，正文保持横排。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 使用水墨、器物、建筑、纹样或自然意象作为主视觉，避免廉价素材拼贴；图表以墨色层级和一处朱砂/主题强调色表达。
- 装饰取自印章、窗棂、纸张、细线或留白，同页只选一到两种母题；不要把国风纹样贴在每张卡片上。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“故宫墨红”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
