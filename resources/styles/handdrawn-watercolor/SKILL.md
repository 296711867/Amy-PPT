采用手绘水彩绘本风格，整体以低饱和暖色与海洋系浅蓝为主，营造治愈、温柔、富有故事感的视觉氛围。

## 配色
主色包含天蓝 #87CEEB、湖蓝、米白 #F5F5DC、浅卡其、暖黄色与橘粉色，辅以淡灰蓝、浅棕和少量珊瑚红 #FF7F50 作点缀。背景多为大面积留白或纸张质感的浅米色底。

## 排版
标题使用较粗的毛笔/手写风字体，黑色或深棕色，高辨识度且富有情绪；副标题与正文则采用较细的手写字或简洁印刷体，字号层级清晰，整体不强调严肃规范而更注重陪伴感与可读性。

## 插画与装饰
设计元素以彩铅+水彩晕染插画为核心，如海浪、太阳、纸船、雨伞、云朵、天气图标、丝带横幅、手绘边框和轻微纹理底色，图形轮廓柔和自然，带有儿童绘本式的不规则感。

## 布局
偏向上下分区或模块化排布，上方常用大幅场景插画营造情绪，中部放置醒目主标题和副标题，下方根据内容需要放少量说明、便签或卡片。不要默认卡片宫格；留白充足，元素之间呼吸感明显。

## 动画
节奏舒缓，元素入场使用 ease-out 缓动，时长 0.8s–1.2s。插画元素可做轻微浮动或摇摆，文字淡入或从下方轻滑入。

## 适合场景
适合制作面向青少年、心理成长、教育科普类的温暖型 PPT。

## 不要
- 不要使用高饱和、刺眼的颜色
- 不要使用尖锐的几何图形或硬朗的线条
- 不要使用复杂的渐变或强烈的阴影效果
- 不要让布局过于拥挤，保持充足的呼吸感

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 治愈手绘水彩的推荐构图

- 使用一幅统一笔触的水彩主景连接内容，重点靠留白与色块，不拼贴来源不一的小插画。
- 优先主插画 + 观点、场景式叙事、横向旅程、三阶段故事或图文分栏；插画必须形成主视觉，不把素材拆成一堆贴纸卡片。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 插画的线条、笔触、人物比例和色温保持统一，图片占位必须写清语义与建议裁切；数据图表简化为手绘感轴线与清楚数字，不能牺牲准确性。
- 可使用手绘线、纸胶带、邮戳或涂抹色块作为少量锚点；禁止 emoji 代替图标，禁止每个信息点都加独立贴纸底座。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“治愈手绘水彩”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
