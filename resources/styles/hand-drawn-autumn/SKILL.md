# 手绘秋日旅行手账

这是一本被秋风吹开的旅行手账——色调是晾在窗台的南瓜与枫叶，笔触是孩童第一次出游时小心翼翼的描线。整体气质温暖、松弛、带一点天真，像把一段山野漫步的回忆随手贴进了本子里。阅读它的人应该闻得到纸张味，而不是屏幕味。

## 配色

情绪来自十月的午后：阳光晒过的稻穗、刚煮好的南瓜汤、远处砖墙与湖面薄雾。

- 背景：温暖米黄 `#F5E6C8`（像泛黄的牛皮纸，承载所有元素的底）
- 主色：秋日暖棕 `#8B5E3C`（描边、文字骨干、路径，几乎所有的"线条"都用它）
- 强调暖色：砖红 `#C04851` + 枫叶橙 `#E87D3E`（标题色块、点缀、暖色高光，两者拉开明度避免糊在一起）
- 强调冷色：天空蓝 `#6BA3BE`（只在需要一点"清凉呼吸感"时出场，比如水、雾、冷色标签）
- 正文文字：深棕 `#4A3728`（比主色更深一档，保证可读性又不至于冰冷纯黑）

大面积米黄打底，暖棕勾线，橙红做焦点，蓝只作微调——这是这个风格的呼吸节奏。

## 排版

字体要传达"手写的温度"，而不是字号的规范。

- **标题**：圆润的手写体或卡通字体，字重重、字距宽，带一点童趣。可放在手绘标签色块里（如一侧带尖角的色条），让标题像贴在本子上的胶带。
- **副标题/小标题**：用色块或虚线胶囊承载（如"第二天"），既是导航也是装饰。
- **正文**：清晰的无衬线字体，行距宽松（1.7-1.8），让人愿意慢慢读。
- **情绪强调**：关键短句（"超暖！""超美！"）用感叹号 + 色块高亮（橙/蓝/红胶囊），把情绪顶到眼前，而不是加粗了事。
- **层级靠"标签 + 色块"建立**，而不是单纯字号差。

## 插画与装饰

这是风格的灵魂——所有视觉元素都该像被人一笔笔画上去的。

- **插画母题**：小房子（带烟囱与袅袅炊烟）、枫叶、小树、云朵、纸船、雨伞、行李箱、热气球……圆润造型、平涂上色、棕色勾边，绝不写实。
- **手账装饰**：枫叶、星星 `★`、爱心 `♥`、虚线路径、手绘圆圈、小箭头、胶带式标签、对话框、便利贴、胶卷角标。
- **路径感**：用虚线把不同"景点/卡片"串起来，模拟旅行地图上的路线——这是手账叙事的核心。
- 所有装饰都半透明（0.2-0.5），不抢正文焦点，只做氛围。

## 布局

刻意"不规整"，模拟手账的自由贴法。

- **非对称自由布局**：标题、卡片、对话框、插图错落分布，避免网格化。
- **充足留白**：元素之间留呼吸空间，宁可空，不要挤——留白是为了让手绘元素的情绪托住整页节奏。
- **分区用"自然物"**：手绘边框、对话框尾巴、虚线胶囊、色块标签来划分信息模块，而不是用方框生硬切割。
- 视觉上要有"贴上去的层次感"：卡片半透明白底 + 棕色描边，像贴在牛皮纸上的便签。

## 组件与装饰

**标题处理**：标题手写体坐在一条纸胶带贴条上（暖色胶带 + 微倾斜），或配枫叶手绘贴纸点缀标题角。
**卡片**：米纸底，手绘感虚线边框（深棕），允许 1-3° 倾斜，四角可贴半透明胶带；不用规整阴影。
**表格与图表**：表格线画成手绘微抖动的线，表头浅暖橙底；图表粗描边 + 手绘填色（枫红 / 暖黄 / 棕）。
**装饰母题**：枫叶、旅行票根、图钉、虚线路径与小旗子；像一本正在旅行的手账，允许一点点凌乱的生命力。

## 动画

节奏要轻快、有跳跃感，像翻开手账时元素一个个跳出来。

- **节奏**：轻快、活泼，带着探索的愉悦。
- **时长**：单个元素 0.3-0.6 秒；路径（虚线延伸）1-2 秒。
- **缓动**：`ease-out` 或 `ease-in-out`，模拟手绘从无到有的自然出现，不要 linear。
- **效果**：淡入、轻微弹跳（如标题"贴上去"的瞬间）、虚线路径逐步绘制（像用笔连点成线）、装饰元素错峰浮现。

## 图表

如果必须出现图表，也要"手账化"。

- 类型：手绘风示意图、旅行地图、流程图、清单 checklist。
- 所有柱、线、箭头都用棕色描边 + 平涂填色，绝不出现冷硬的渐变柱或默认 office 配色。
- 数据点可以用小图标代替（一片枫叶代表一个景点）。

## 适合场景

旅行手账、生活记录 PLOG、城市漫游笔记、亲子/家庭活动海报、校园社团招新、秋季节日主题分享、读书笔记、美食探店地图。

## 不要做

- 不要冷冰冰的几何图形、不要网格化的规整对齐——那是商务模板，不是手账。
- 不要渐变、不要 3D、不要写实阴影——手绘风靠的是平涂与勾线。
- 不要严肃的衬线体或商务黑体、不要高饱和荧光色。
- 不要把装饰塞满整页——装饰是氛围，不是主体，留白是这种风格的呼吸。

## PPT 演示执行契约（v3）

以下规则是本风格在当前 PPT harness 中的最终执行约束；上文负责视觉 DNA，本节负责把它落成真正的演示文稿。若上文示例与本节冲突，以本节及全局 Layout Skill 的结构安全规则为准。

### 与 Layout Skill 的边界

- 本风格只决定颜色角色、字体气质、图像处理、图表观感、形状和装饰语言；页面角色、阅读路径、信息分组、画布安全区、碰撞与高度预算由 Layout Skill 决定。
- 这是固定比例 PPT 画布，不是响应式网页。先确定“观众 3 秒后应记住的一句话”，再选封面、数据、对比、过程、时间线、概念、总结或图片主导等页面角色。
- 每页只设一个主结论和一个主视觉焦点，通常保留 2–4 组支撑信息。内容过多时先合并、删减或换构图，不缩小字号、不越过安全区。
- 全套保持统一的颜色角色、字体组合、图像色温和装饰母题，但相邻页面应变化轮廓，不能连续复制同一种卡片网格。

### 手绘秋日旅行手账的推荐构图

- 围绕一条旅行路径或一个秋日场景组织信息，邮票、纸胶带和手写标记只服务地点与时间。
- 优先主插画 + 观点、场景式叙事、横向旅程、三阶段故事或图文分栏；插画必须形成主视觉，不把素材拆成一堆贴纸卡片。
- 封面保持简洁；内容页让标题、主视觉/主图表和结论形成明确先后。留白围绕焦点组织，既不能拥挤，也不能出现内容只堆在上半页的意外空洞。

### 字体与信息层级

- 使用 Layout Profile 或 design contract 给出的实际字体和字号；风格只约束字形气质。无覆盖时遵守画布自适应字号下限，标题、二级标题、正文、辅助文字四级必须一眼可辨。
- 页面标题优先写成结论句，并保持单行；二级标题命名一个步骤、证据或观点，正文写短句而不是网页说明文。内容放不下时先改文案或布局，不压缩到投影不可读。
- 多行正文和模块默认左对齐；居中只用于封面、金句、单数字或极短标签。同组标题—正文间距、行距和对齐线保持一致。

### 视觉素材、图表与模块

- 插画的线条、笔触、人物比例和色温保持统一，图片占位必须写清语义与建议裁切；数据图表简化为手绘感轴线与清楚数字，不能牺牲准确性。
- 可使用手绘线、纸胶带、邮戳或涂抹色块作为少量锚点；禁止 emoji 代替图标，禁止每个信息点都加独立贴纸底座。
- 图片、图标、图表和装饰必须支持当前结论。图标使用统一风格的 SVG/矢量图，不用 emoji、字符图标或无意义贴纸；需要替换的图片位应使用明确比例、用途和裁切建议的语义占位。
- 卡片不是默认布局。只有并列、对比、步骤或分类确实需要边界时才使用容器；同组容器的圆角、边框、阴影、图标底座和强调方式必须完全一致，且禁止卡片内再嵌套卡片。

### 反 Web UI 硬约束

- 禁止导航栏、侧边栏、标签页、按钮、搜索框、表单、状态栏、浏览器/手机窗口壳和“功能入口”式布局，除非内容本身是在展示对应产品界面。
- 禁止默认使用 dashboard、bento、四宫格/六宫格卡片墙、胶囊标签云、悬浮玻璃面板或顶部 hero + 下方功能卡片的网页套路。
- 禁止把每条提纲机械转换成一个可见模块。先围绕主结论编辑证据，再选择主图、主图表、对照、时间线、过程、引语或数字等 PPT 表达。
- 装饰不能穿过文字、抢占安全区或填补无意义空白；动画跟随阅读顺序，控制在淡入、轻移、擦除或图表生长等演示动作内，不模拟网页交互。

### 输出前自检

1. 关闭颜色与装饰后，这页是否仍能在 3 秒内读出主结论和阅读顺序？
2. 页面是否像一张演示文稿，而不是网站首页、后台面板、组件库或信息流？
3. 是否只有一个主焦点，支撑信息数量受控，并且所有正文都在安全区内、无碰撞、无截断？
4. 本页是否真正体现“手绘秋日旅行手账”的独特色彩、字体、图像或形状语言，而非只换背景颜色？
5. 与相邻页相比，是否保持同一视觉系统但使用了不同且适合内容的页面轮廓？
